​Part 1 (Scope of Variables / Error):
​Demonstrates the concept of Variable Scope.  
​The variable myName is declared inside firstButton_Click, so trying to use it inside secondButton_Click results in an ERROR because it is out of scope.  
​Part 2 (Displaying Information):
​Reads input data from text fields (txtName, txtstudentid, txtdepartment, txtsemester).  
​Concatenates (joins) these values together and displays the result in the label lblout.  
​Part 3 (Clearing Inputs):
​Shows how to clear text fields (TextBoxes) using "", .Clear(), or string.Empty.  
​Part 4 (Type Casting / Type Conversion):
​Demonstrates how to convert one data type into another (Explicit Casting).  
​For example, converting a decimal to an int or double using the (int) or (double) syntax.
